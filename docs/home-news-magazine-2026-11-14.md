# 首页资讯局部模块

唯一范围是首页 `#news`。保留原浅色背景、三篇文章的中英文数据与路由；使用错层杂志封面：宽主推、竖封面、低横封面，电蓝底层与lime / pink / orange主题色。

`home-news-magazine.js` 共用构建输出与局部浏览器控制器，`home-news-magazine.css` 所有样式限制在 `#news[data-news-magazine]`。避免使用原 `.news-card`，使本模块不重复绑定全局入场动画。一个局部 IntersectionObserver 负责逐卡遮罩揭示，独立折角与图片视差不移动文字和点击边界；中英文切换不重建卡片或控制器。
